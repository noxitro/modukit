# hibernation

休止中のアプリが Play ストアで自動更新されない問題を直すためのツールです。

## 原因

Android 12 以降は、しばらく（標準で約 3 か月）使っていないアプリが自動で
**休止状態**（App hibernation）になります。休止中のアプリは Play ストアの更新対象から外れ、
「利用可能なアップデート」にも出てきません。アプリを一度起動すると休止が解けて、また更新されるようになります。

Galaxy の **ディープスリープ中のアプリ**（Samsung 独自の機能）も同じで、
アプリを起動するまで Play ストアから更新されません。

どちらも、アプリを休止させない設定にすれば直ります。

## 設定アプリで直す（PC 不要）

### Pixel など（Android 12 以降）

1. 設定 > アプリ > **使用されていないアプリ** で、休止中のアプリを確認する
2. 各アプリの「アプリ情報」で、次のスイッチを OFF にする（OFF にすると休止も解除されます）

   | Android | スイッチの名前 |
   | --- | --- |
   | 13 以降 | 使用していないアプリを一時停止する（「使用していない時はアプリを一時停止する」「使用していないアプリを管理する」の場合もあります） |
   | 12 | 権限を削除して空き容量を増やす |

3. Play ストア右上のアイコン > **アプリとデバイスの管理** で、アップデートを確認する

一括で設定したいときは、下の ADB スクリプトを使ってください。

### Galaxy

1. 設定 > バッテリー > **バックグラウンドでの使用を制限**（機種によっては「デバイスケア」の中）
2. **未使用のアプリをスリープ状態にする** を OFF にする（今後、自動でスリープに入らなくなります）
3. **ディープスリープ中のアプリ** を開き、一覧からアプリを外す（アプリ自体はアンインストールされません）
4. 自動スリープ自体は残したい場合は、2. を OFF にする代わりに、更新したいアプリを
   **自動的にスリープ状態にしないアプリ** に追加する

One UI のバージョンによって表記が少し異なります。

## ADB で一括で直す（hibernation.sh）

Pixel などの休止状態を、全アプリまとめて解除・無効化します。
処理内容は、設定アプリで各アプリのスイッチを OFF にするのと同じです。

必要なもの: PC と adb（USB デバッグまたはワイヤレスデバッグ）。
端末だけで使う場合は、Shizuku の rish など ADB 権限のシェルから実行できます。

```sh
adb push hibernation.sh /data/local/tmp/

# 休止中のアプリを確認するだけ（何も変更しない）
adb shell sh /data/local/tmp/hibernation.sh

# 休止を解除して、今後も休止させない
adb shell sh /data/local/tmp/hibernation.sh fix
```

実行後、Play ストアの「アプリとデバイスの管理」でアップデートを確認してください。

| コマンド | 内容 |
| --- | --- |
| `check`（省略時） | 休止中のアプリと、まだ自動休止の対象になっているアプリ数を表示 |
| `fix` | 休止中のアプリを起こし、アプリを自動休止の対象外にする |
| `undo` | 自動休止の設定を初期値に戻す |
| `--user ID` | 対象ユーザーを指定（省略時は現在のユーザー） |
| パッケージ名 | 指定したアプリだけを対象にする（例: `fix com.example.app`） |

対象はランチャーに表示されるアプリ全部です（プリインストールの YouTube なども含みます）。
ランチャーに表示されないアプリは、もともとシステムが休止の対象外にしています。

### 出力の見方

出力は Windows のコンソールでも文字化けしないように英語にしています。

| 出力 | 意味 |
| --- | --- |
| `Hibernating apps` | 休止中のアプリ（Play ストアが更新しない） |
| `N of M app(s) can still be hibernated automatically.` | まだ自動休止の対象になっているアプリ数 |
| `Woke up: パッケージ名` | 休止を解除したアプリ |
| `Exempted N app(s) ...` | 自動休止の対象外にしたアプリ数 |
| `Disabled user apps` | 無効化されているアプリ。Galaxy ではディープスリープ中のアプリです（スクリプトでは解除できないので、設定アプリから外してください） |

### 実際に実行するコマンド

`fix` はアプリごとに次のコマンドを実行します（設定アプリのスイッチを OFF にしたときと同じ処理）。

```sh
appops set --uid <パッケージ名> AUTO_REVOKE_PERMISSIONS_IF_UNUSED ignore
cmd app_hibernation set-state <パッケージ名> false           # 休止中の場合
cmd app_hibernation set-state --global <パッケージ名> false  # 休止中の場合
```

### 注意

- `fix` の後に入れたアプリは対象外です。アプリを入れたら、もう一度 `fix` を実行してください。
- 休止状態と「使用していないアプリの権限の自動削除」は同じスイッチなので、権限の自動削除も止まります。
- 休止したときに削除された権限は元に戻りません。アプリを次に使うときに許可し直してください。
- `device_config put app_hibernation app_hibernation_enabled false` で機能ごと止める方法もありますが、
  Google のサーバー側の設定で元に戻されることがあるため、このスクリプトでは使っていません。
